# Paste these into Firebase
Generated from the templates one directory up — do not edit these by hand,
edit the source and re-run `python scripts/build-firebase-templates.py`.

Console: Authentication -> Templates -> pick the template -> pencil icon.
Paste the whole file into the message body. Set the subject to the one below.

`%LINK%` must survive. It is the one-time URL; without it the email has
nothing to click. Leave the password-reset action URL at its default.

## password-reset.html

**Subject:** `Reset your NEET Companion password`

## sign-in-link.html

**Subject:** `Your NEET Companion sign-in link`

## verify-email.html

**Subject:** `Confirm your email for NEET Companion`
